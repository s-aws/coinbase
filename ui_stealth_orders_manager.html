📐 How Repricing Works
Each ticker update computes a reference price (midpoint, last trade, or top of book). The order is then aimed at:
● Target  = reference ± Target Distance  (ideal resting position)
● Boundary = reference ± Max Distance  (furthest allowed before forced reprice)
For a BUY: order rests below the reference. For a SELL: order rests above it.
If the order drifts past the boundary due to market movement, it is forced back to the boundary price on the next tick.
Ticker field used as the reference anchor.
Midpoint = (bid+ask)/2  ·  Top of Book = best bid (BUY) or best ask (SELL)
Percentage: distances are fractions of the reference price (0.01 = 1%)
Absolute: distances are fixed dollar amounts (e.g. 50 = $50)
Ideal distance from reference. The order is repriced toward this on every tick.
Example (BUY, %): ref=40000, target=0.01 → order aims at 39600
